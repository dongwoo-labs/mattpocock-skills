# Teaching pedagogy

Read this reference when designing a lesson or deciding what the user should learn next.

## Knowledge, skills, and wisdom

Deep learning combines:

- **Knowledge** from high-quality, high-trust resources.
- **Skills** acquired through relevant interactive lessons.
- **Wisdom** developed through interaction with learners and practitioners.

Before `RESOURCES.md` is well populated, focus on finding trustworthy resources and ground lessons in them. Some topics are knowledge-heavy, while others are skill-heavy.

## Fluency and storage strength

Distinguish between:

- **Fluency strength**: retrieving knowledge in the moment.
- **Storage strength**: retaining knowledge over time.

Storage strength is the goal. Use desirable difficulty through retrieval practice and spacing; use interleaving for skills practice when different but related topics benefit from being mixed.

## Choosing the next lesson

Keep the user in their zone of proximal development: challenge them just enough. If they specify what they want to learn, follow that request. Otherwise, read `learning-records`, relate them to the mission, and choose the most relevant next skill.

Teach only the knowledge required for the target skill, then let the user practise it through an interactive feedback loop. For skill acquisition, effortful retrieval and immediate feedback are useful. Interactive lessons may use quizzes or light in-browser tasks, or guide the user through real-world steps.

For quizzes, make answers exactly the same number of words and, when possible, characters. Do not reveal answers through formatting.

## Resources and reference documents

Gather knowledge from trusted resources and track them in `RESOURCES.md`. Cite sources in lessons for claims that need support. Create reference documents as compressed, reusable units of knowledge; possible forms include programming syntax and snippets, process algorithms and flowcharts, exercise routines, poses, and glossaries. Once a glossary exists, use its terminology consistently in every lesson.

## Wisdom and communities

When a question requires real-world wisdom, attempt an answer while ultimately directing the user toward a high-reputation community where they can test their skills. Respect a stated preference not to join a community.
